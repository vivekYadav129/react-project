# ⚛️ React Creative Lab

A collection of high-performance, modern React applications and experiments. This workspace serves as a playground for exploring the latest React features, state management patterns, and UI/UX design systems.

---

## 📂 Projects Overview

| Project | Stack | Description | Status |
| :--- | :--- | :--- | :--- |
| **[Vite Project](./vite-project)** | React 19 + Vite + Tailwind | A lightning-fast Todo App with local storage persistence and advanced filtering. | ✅ Stable |
| **[React Project](./react-project)** | CRA + Axios | A full-stack Task Manager interface with CRUD operations and backend integration. | 🛠 In Progress |

---

## 🚀 Getting Started

### ⚡ Vite Project (Todo App)
The Vite project is built for speed and efficiency.
```bash
cd vite-project
npm install
npm run dev
```

### 📦 React Project (Task Manager)
The classic React project setup with internal service layers.
```bash
cd react-project
npm install
npm start
```

## 🎨 Shared Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) for utility-first responsive design.
- **Tools**: [Vite](https://vitejs.dev/) for ultra-fast development and [PostCSS](https://postcss.org/).
- **Linting**: [ESLint](https://eslint.org/) for code quality.

---

## 🛠 Features Across Lab
- **Responsive Design**: All apps are mobile-first and fully responsive.
- **Modern State Management**: Using Hooks (`useState`, `useEffect`) and efficient data flows.
- **Optimized Performance**: Leveraging Vite's build pipeline and React's concurrent rendering.
